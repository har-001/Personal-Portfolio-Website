# Project Review & Strategy

## Current Project Assessment
The existing single-page portfolio works well functionally:
- Clean semantic HTML structure.
- CSS design system with custom properties.
- Dynamic project fetching from GitHub API.
- Integrated certificate modal.
- Active contact form via EmailJS.

## What Needs Upgrading (per Build Kit)
1. **Hero Design:** Move from standard center text + floating photo to the **Asymmetrical Layout**:
   - Left: Clear, bold typography with Headline ("Data Analytics" / "AI Enthusiast"), Tagline, CTAs.
   - Right: **Physical 3D Titanium ID-Card** with tactile metallic edge, realistic reflection highlights, and soft studio ambient shadow.
2. **Color Palette:** Upgrade from high-saturation cyan/purple gradient to the subtle, luxurious **Midnight Blue** Apple-like palette.
3. **AI Hub Separation:** Cleanly separate experimental autonomous agents (N8N automation & NIVA assistant) into a dedicated page (`ai-hub.html`) featuring the interactive Silver Robot mascot.
4. **Data Verification:** Remove speculative proficiency percentages; replace with structured, clean skill clusters backed by coursework and actual projects.
5. **Robust Contact Flow:** Enhance contact submission with graceful error handling, direct fallback email, and LinkedIn channels.
