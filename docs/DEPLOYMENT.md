# 🚀 Free Live Deployment Guide — Harshit Mishra Portfolio

Follow any of these 2 simple methods to get your website **LIVE** on the internet with a free domain!

---

## Method 1: Vercel (Recommended — Takes 1 Minute) ⚡

1. Push this folder to your GitHub account (`@harshit-001-it` or `@har-001`).
2. Go to **[vercel.com](https://vercel.com)** and sign in with your GitHub account.
3. Click **"Add New Project"** ➔ Import your `Personal-Portfolio-Website` repository.
4. Click **"Deploy"**.
5. 🎉 Your site will instantly be live at a custom URL like:
   `https://harshit-mishra-portfolio.vercel.app`

---

## Method 2: GitHub Pages (Free GitHub Hosting) 🐙

1. Go to your repository on GitHub: `https://github.com/harshit-001-it/Personal-Portfolio-Website`
2. Click **Settings** ➔ **Pages** (in the left sidebar).
3. Under **Build and deployment** ➔ **Source**, select **GitHub Actions**.
4. Push your code. GitHub will automatically deploy your site!
5. 🎉 Your site will be live at:
   `https://harshit-001-it.github.io/Personal-Portfolio-Website/`
